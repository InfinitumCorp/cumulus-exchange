# Cumulus Data Exchange

Console for Infinitum Corporation's Cumulus Data Exchange.

Opt-in datasets, explicit consent, an 85% owner share, and one soulbound CDAT license per sale. The ledger in this app is a local preview of Firmament. Military editions and government workloads stay off the exchange.

Signed in for the demo as `alex@cumulusmail.cloud`.

```sh
npm install
npm run dev
```
