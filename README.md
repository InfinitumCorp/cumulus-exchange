# Cumulus://Cloud

One product. Cumulus://Cloud is Cumulus Drive. The Exchange is Cumulus://Cloud.

Opt-in datasets, explicit consent, an 85% owner share, and one soulbound CDAT license per sale. The ledger in this app is a local preview of Firmament. Military editions and government workloads stay off the product.

The demo ledger label is `demo.alex@cumuluscloud.app`. That address is not an account and not a mailbox. The ledger stays in the browser.

Private Drive files use a server session, a local byte directory, and file-backed metadata. Setup is in `docs/drive-storage.md`.

```sh
npm install
npm run dev
```
